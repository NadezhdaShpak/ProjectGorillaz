# Quest Gorillaz - Текстовый квест
**Веб-приложение с динамическими сюжетными ветвлениями и системой прогресса**

---

## 🌟 **Особенности проекта**
- **3 уникальных сюжета**:  
  ▪ КВИЗ по вселенной Гарри Поттера  
  ▪ По страницам волшебных русских сказок  
  ▪ История Древней Руси  
- Сохранение прогресса в сессии (имя игрока, пройденные шаги)
- Возможность переигрывания с сохранением статистики
- Адаптивный интерфейс с JSP-шаблонами
- 97% покрытие критической логики тестами

---

## 🛠 **Технологический стек**
```plaintext
▪ Backend: Java 17, Servlet API 4.0, JUnit 5  
▪ Frontend: JSP, JSTL, Bootstrap 5  
▪ Сборка: Maven, Tomcat 9  
▪ Архитектура: MVC, слоистая структура (Controller-Service-Repo)
