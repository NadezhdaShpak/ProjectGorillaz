# Quest Gorillaz - Текстовый квест
**Веб-платформа для создания и прохождения текстовых квестов**   
Платформа позволяет пользователям проходить текстовые квесты с бинарным выбором, создавать новые сценарии, а система автоматически собирает статистику успешности прохождения. Реализовано на Java EE стеке с полноценным тестовым покрытием.

---

## 🌟 **Особенности проекта**
- **Аутентификация**: регистрация новых пользователей, вход/выход
- **3 бызовых квеста**:  
  ▪ КВИЗ по вселенной Гарри Поттера  
  ▪ По страницам волшебных русских сказок  
  ▪ История Древней Руси
- **Конструктор квестов**:  
    ▪ Создание вопросов с 2 вариантами ответов  
    ▪ Пометка верного/неверного ответа
- **Статистика**:  
  ▪ Глобальная (процент побед/поражений)  
- Сохранение прогресса в сессии (имя игрока, пройденные шаги)
- Возможность переигрывания с сохранением статистики
- Адаптивный интерфейс с JSP-шаблонами
- 97% покрытие критической логики тестами

---

## 🛠 **Технологический стек**

▪ Backend: Java 17, Servlet API 4.0, JUnit 5  
▪ Frontend: JSP, JSTL, Bootstrap 5  
▪ Сборка: Maven, Tomcat 9  
▪ Архитектура: MVC, слоистая структура (Controller-Service-Repo)  


## ✅ **Тестирование**
Покрытие API:
▪ тесты для 12 REST-эндпоинтов
▪ Проверка авторизации и ролевой модели

Технологии:  
▪ Spring Boot Test   
▪ MockMvc для эмуляции HTTP-запросов

Mocking:   
▪ Mockito для изоляции компонентов   
▪ @Spy для частичного мокажирования
